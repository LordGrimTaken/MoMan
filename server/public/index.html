Install MoMan

MoMan is a native Android app. Here is how to get it.

Download

Checking the latest release...

Download APK

Which file? Choose arm64-v8a for almost all phones made in the last several years. Use universal if you're unsure or have an older device; it's larger but works everywhere.

Tip: only download MoMan from momanreader.com or from inside the app. If you can, compare the file size shown here with what you downloaded.

Install steps

  1. Tap the download button and save the APK.
  2. Open the file from your notification shade or Files app.
  3. If asked, allow Install unknown apps for your browser or file manager (Settings, Apps, Special access).
  4. Tap Install, then Open.
  5. In MoMan, add your own sources/extensions from Browse.
  6. Afterwards, MoMan updates itself in-app.

Questions

How do I install an APK from outside the Play Store?
Open the downloaded file. Android will ask you to allow installs from that app (your browser or Files). Turn on Allow from this source, go back, and tap Install. You can turn the permission off again afterwards.
Does MoMan come with sources?
No. MoMan is a reader, not a library. You bring your own extensions and sources, which are provided by third parties.
Is it legal?
MoMan hosts no content and does not provide any sources. It's a reading tool. What you read through it is your responsibility; please respect creators and the copyright laws that apply to you, and support official releases where you can.
Is it free? Are there ads?
It's free. There are no ads, no analytics and no tracking. See the privacy page.
Which APK should I pick?
arm64-v8a for most modern phones; universal if unsure.
How does it relate to Mihon?
MoMan is a fork of Mihon (Apache-2.0). It is an independent project and is not affiliated with, endorsed by, or supported by Mihon or its developers. Please don't ask them for MoMan support.
